# HexSoftwares_AI-Voice-Asisstant_Friday

Friday is a Python-based AI-powered virtual assistant that responds to voice commands.  
It integrates speech recognition, text-to-speech, and intent classification to perform tasks like:

- Answering questions using Wikipedia
- Playing music on YouTube
- Giving time & date updates
- Saving reminders in a text file
- Greeting and exiting commands
- Learning new commands continuously

## Tech Stack
- Python 3
- SpeechRecognition
- pyttsx3 (Text-to-Speech)
- pywhatkit
- scikit-learn (for intent classifier)
- Wikipedia API

## Features
- Voice-controlled input and responses
- Stores reminders locally
- Expands with new user-defined intents
- Lightweight and customizable
